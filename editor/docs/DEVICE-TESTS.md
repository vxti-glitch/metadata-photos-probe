# First Flutter/Swift editor device check

Sign the delivered unsigned IPA using the same authorized channel as before. Install the **Zlarp Metadata** editor alongside Metadata Probe. Confirm version **0.3.0 / build 4** and the phone's actual iOS version/build. Cloud/simulator results do not replace this integration test.

1. Choose a disposable JPEG or the previously working HEIC through Photos, then another through Files. Confirm the source name, origin, camera details and preview identify the intended file. Photos-original import intentionally excludes prior visible edits and refuses Live Photos; those restrictions must be clear rather than silently converting.
2. Change make/model and optionally the image lens. Blank lens preserves the existing value; ordinary ASCII changes are required for HEIC. Run the write and inspect the frozen output's camera fields, location/presentation and independent quality result. Known mismatch must block export. A disclosed incomplete result remains incomplete even after acknowledgment.
3. Save a copy to Files, upload that exact copy through Safari at iCloud.com/photos, then check the synced Photos result's camera, location, orientation, appearance and complete source-label text. A copy confirmation or opened browser is not upload confirmation. Keep the original file and avoid deleting valuable photos to bypass duplicate warnings.
4. Close and reopen the editor. Recover the session and export only the intended frozen output. Cancel an import/export and a write where possible: operations must end with a truthful result and no stale output. Delete an editor session; only its app-owned copies should disappear. Check limited/denied Photos access and a cloud-only import separately.
5. Finish the remaining video gate with a changed-metadata MP4 fixture and a short real portrait camera MOV with sound. Leave lens empty. Verify native readback, no failed checks, playback, audio, orientation/duration and actual Photos display/attribution. Record unsupported structures rather than transcoding or dropping tracks.

The earlier HEIC probe success qualifies that tested engine case; this test qualifies its new Flutter/native integration. Opaque HDR/MakerNotes/video side-data, large-file/device performance, post-upload exact bytes and every format/encoding remain distinct acceptance gates. Broader fields, presets, randomization, selective removal and batch processing follow their planned milestones after this foundation's results.
