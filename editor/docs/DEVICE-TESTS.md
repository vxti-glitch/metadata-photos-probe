# Editor 0.4 physical-device acceptance

Use the user's authorized signing channel, install Metadata Editor alongside the preserved probe, and verify version 0.4.0/build 5. Primary device: iPhone 15 Pro Max, reported iOS 27.2; record actual OS/build. Cloud/simulator checks are separate.

1. Import disposable JPEG, HEIC, PNG (with transparency), MP4 and portrait MOV with sound, from Files and Photos as applicable. Turn Live Photo off for still fixtures. Confirm intended source name/origin. The app retrieves Photos originals; prior visible adjustments are not applied.
2. In Presets choose Apple → iPhone 15 Pro Max → Main Camera. Confirm make/model/lens, aperture1.78, physical focal6.765 and equivalent24, randomized ISO/shutter/dates. Select Ultra Wide and Telephoto and confirm coherent values. Then check a second brand/model: unknown physical specifications must not retain the original phone's focal length. Exact EXIF lens strings are script-derived only where marked; other labels are descriptive.
3. Manually set exposure, offsets, location and descriptive fields on an image. Test northern/southern and eastern/western coordinates plus below-sea-level altitude. Remove selected fields in another disposable output. Inspect native readback in Details and an independent metadata reader where available; unsupported duplicates must report an error, never imply successful privacy removal.
4. Save a manual preset and a randomized profile recipe. Restart the app, apply them, export/import preset JSON, and ensure distinct files get independent frozen random values. Retry must reuse an interrupted item's frozen values.
5. Import a mixed batch, process, cancel a running batch, restart and retry unfinished files. A bad/unsupported item must not erase successful results. Review individual failures, select ready outputs, export multiple copies. Names must be IMG_#### with the correct preserved extension and no collisions/overwrites.
6. Check the compressed-media/presentation report. Failed checks block export; incomplete checks remain incomplete after acknowledgment. Confirm playback, sound, orientation, duration, color/transparency and HDR appearance. Videos use QuickTime ISO/shutter/aperture/lens fields; their actual Photos display is a separate physical test. Flash/metering are still-only.
7. Export each changed output to Files and upload that exact file manually through Safari/iCloud Photos. After syncing, inspect camera/exposure/location, filename and the complete source-attribution text. Record whether a Saved from label exists separately for each format. A duplicate warning is not upload success: use fresh disposable fixtures and retain valuable originals.
8. Download that uploaded asset using iCloud's **Unmodified Originals** option to Files. In the app's optional Details choose Verify iCloud original and select the downloaded file. Exact hash/byte equality proves preservation of the selected processed output; matching rounded MB alone is insufficient. A Most Compatible download can convert and is not this test.
9. Deny/limit Photos permission, cancel imports/exports, test cloud-only originals and low storage. Delete/clear local sessions: Photos/provider originals must remain, saved presets remain. Test a larger clip for responsiveness/memory/thermal behavior before production qualification.

Keep original, processed and downloaded originals as paired evidence. Do not upload private media/GPS into GitHub or CI. UI screenshots establish displayed fields and attribution, not full byte integrity. Source/build/simulator/device/signing/iCloud results must remain distinct. Stop at this release's device results before claiming universal format compatibility or production release readiness.
